# CityGenesis

TypeScript、Three.js、Viteによる都市経営シミュレーションです。

## 開発

Node.jsはVite 7が対応するバージョン（20.19以上または22.12以上）を使用してください。
依存関係の導入後、`npm run dev`で開発サーバー、`npm test`でテスト、
`npm run build`で型検査とビルドを実行できます。

この初回登録時点の作業コピーにはlockファイルとnode_modulesがありません。
依存関係の導入、テスト実行、ビルドは初回アップロード作業では実施していません。

## 含まれるファイル

- `src/`: アプリケーションと保存・読み込み処理のソース
- `tests/`: バス運行・復旧、保存データ転送、ブラウザー起動設定のテスト
- `public/THIRD-PARTY-LICENSES.txt`: サードパーティーのライセンス
- `index.html`、`package.json`、`tsconfig.json`: エントリーと設定

`package.json`に残る`bench:*`、`test:p2:browser`、`qa`の参照先スクリプトは
この作業コピーには含まれていないため、実行できません。

都市の保存データ、認証情報、ブラウザープロファイル、作業記録、ビルド成果物は
登録対象外です。既存Sitesへの公開・更新はこのリポジトリの初回登録では行いません。

## アップデート履歴

ゲームのトップ画面にある「更新履歴」から、その画面に含まれる変更点を確認できます。

### 2026-10-18：住民・転入モデル改善

`feature/resident-arrivals` の実装を、ユーザーの公開指示に基づいてmainへ取り込みました。正式な公開先は https://testman40.github.io/citygenesis/ です。

- マップ端の外部接続道路から、経路と空室のある完成住宅へ世帯単位で転入。車が住宅へ到着した時点で人口へ加算
- 住宅を指定しただけでは住民・通勤車を増やさず、転入車と住民の通勤車を分離
- 世帯・家族構成、子供・大人・高齢者、住所、職場、現在の行動と1日の予定を確認できる「都市情報 → 住民・世帯」ビュー
- 住民を選んでカメラ追跡。現在位置・移動経路を表示し、停止中は行動も停止
- 大人の人数と居住地から通勤を計算。近い職場にはバス停がなくても徒歩通勤し、通勤車は時間をずらして出発
- 往復の通勤量を同時に道路へ載せる旧方式から、住民モデルでは片道の通勤需要へ変更

125件のテスト、型検査、本番ビルドが成功。Chromiumで転入・保存復元・住民情報と追跡・スマートフォン幅の表示を確認しています。

既存人口を保って世帯へ移行します。年齢層と日々の行動はゲームの生活モデルで、個人ごとの実車バス乗降・加齢・出生は未実装です。転入中の状態と世帯IDは、保存バージョン4/5内の任意項目 `residents` に保存します。旧形式の都市を読み込めます。新しい住民情報を保持するには、この機能に対応した版を使用してください。

### 2026-10-18：街のにぎわい改善版

`feature/living-city-gameplay` の実装も、住民・転入改善と合わせてmainへ取り込みました。

- 近景の歩行者と、既存の需要をもとにしたバス停の待ち客（人数は代表表現）
- 道路接続・距離・住宅容量に応じた公園と広場の満足度・住宅需要効果
- 施設・地下管・橋の建設と撤去の取り消し、やり直し
- 路線ごとの利用者・輸送枠・乗車人数・維持費と、運賃を仮定した収支試算（運賃徴収は行いません）
- 「赤字都市の再建」「川の両岸を結ぶ」「循環バスの初運行」の3シナリオ

都市ファイルのversion 4/5とフィールド構造を維持します。歩行者と建設履歴は保存せず、課題の進捗はブラウザー内の都市管理情報に保持します。既存の公園・広場にも新しい効果を適用します。

### 2026-10-18：街の暮らし拡張版

`feature/city-life-expansion` の実装をmainへ取り込みました。正式な公開先は https://testman40.github.io/citygenesis/ です。

- 発展目標と新規達成時の通知
- 保存都市の名前・景観画像・日時、直近3件の手動保存前バックアップ、別スロットへの復元と削除
- 川の両岸を結ぶ橋（道路・車両・バスに対応）
- 全車帰庫後に待ち時間を置く、バスの繰り返し運行
- 人口・満足度・収支の前月差と、変化した条件の表示
- 公園・広場の配置、景観描画、維持費と撤去
- 明示的にオンにするBGM・操作音・建設音と、ズームに応じた車両音・市民の合成したざわめき
- BGMと市民の環境音へのローカル音声ファイル指定、音量の個別調整

従来の都市を読み込めます。都市ファイルのversion 4/5・フィールド構造は維持し、橋は河川上の道路、公園・広場は施設値3/4として保存します。新しい施設や橋を使った都市の読込には、対応する最新版が必要です。

都市名・画像・バックアップ・自動運行設定・音設定はブラウザー内で管理し、都市ファイルには含めません。内蔵の市民音は録音会話ではなく合成したざわめきです。この版の時点では公園・広場は景観施設です。作業ブランチで近隣住宅への効果を追加しています。

詳細は [開発工程表](DEVELOPMENT_PLAN.md) を参照してください。

### 2026-10-17：街づくり操作改善版

mainに公開済みの改善です。正式なゲーム公開先は https://testman40.github.io/citygenesis/ です。

- 建設・都市情報・公共交通・経営・保存のメニューを整理
- 問題に合わせた「次にすること」と、関連する操作・区域への案内を追加
- 道路・区画の建設と撤去をドラッグ単位で取り消す機能を追加
- 都市の建設から入居・就業・収支確認までの7段階チュートリアルを追加
- バス復旧診断の確認地点へ移動する操作を追加
- トップ画面から開けるアップデート履歴を追加

都市保存形式は維持しています。取り消しは道路・区画が対象で、時間の再生などで履歴を終了します。

### これまでの基本機能

都市建設と経営、交通・バス運行、電力・上下水道・公共サービス、都市情報、保存・読込と都市ファイルの移動。

## GitHub Pages向けのビルド

`npm run build -- --base=/citygenesis/` で生成した `dist/` を、公開用の `gh-pages` ブランチへ配置します。`.nojekyll` を含め、Pagesの配信元は `gh-pages` のルートを使用します。
